Onboarding

Sign-in to a bot working in a channel in under thirty minutes. The only secret a person pastes is a model provider key. Everything else is an OAuth popup, a GitHub App install, a manifest to apply, or one line in sshd_config.

3 · Files

Everything the team can see, with where it came from. Screenshots from Tester sit next to Nadia's release notes. The right panel previews; "open in thread" takes you to the message it was posted in.

Every team's files are one folder tree over two stores. Text configuration and durable pages are backed by a git repo. Files posted in a channel land under channels/<name>/ in Files storage, not in git — the tree, breadcrumb and list don't distinguish the two stores, but nothing there can be pushed to GitHub or diffed in History. Bot outputs land in pages/, which is git. memory/ is the human-editable mirror of the team's Hindsight bank — edit facts/ and it's re-retained; delete and it's forgotten.
