# Avatar sources

- `men/`, `women-hijab/`, `women-modest/` — DiceBear "Avataaars" style, designed by Pablo Stanley
  ("Free for personal and commercial use" per dicebear.com/styles). Generated via
  `https://api.dicebear.com/9.x/avataaars/svg` with the seeds `man1..10`, `hijab1..5`, `modest1..5`.
  Read DiceBear's licence page before shipping.
- `bots/` — Google Noto Emoji artwork, fetched from
  `https://fonts.gstatic.com/s/e/notoemoji/latest/<codepoint>/emoji.svg`. The googlefonts/noto-emoji
  README states image resources are under Apache License 2.0 (keep the licence notice with the files).
- `bots/brain-bot.svg` — original artwork drawn for this project; no third-party licence.
