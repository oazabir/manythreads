# manythreads

A self-hosted team collaboration platform where people and bots work together: channels, threads, bots and a shared Brain.

- [Install manythreads for your team](docs/deploy/self-host.md): one machine, Helm on k3s, first administrator, first model provider.
- [Your team's first week](docs/guide/first-week.md): what a team lead can do on day one, and what is not built yet.

Engineering rules and build commands for contributors start in `CLAUDE.md` (`AGENTS.md` is a link to it). Project status is in `STATUS.md`.
